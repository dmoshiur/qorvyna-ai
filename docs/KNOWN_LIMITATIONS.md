# Known limitations and release blockers

- **Live checks:** Production domain, DNS, Firebase authorized domains, GitHub OAuth app, provider credentials and actual performance are not verified. No deploy, native-device check, Firebase emulator/rules test or backup restore has been performed in this stage.
- **Providers:** Pooled Groq chat coordinates a conservative shared unknown-organization quota ledger via Firestore, but organization identities are not verified and direct non-pooled calls do not participate. Independent authorized organizations, priority, full usage aggregation, P50/P95, and a latency circuit breaker are not implemented. The ledger has not been tested against live Groq or a Firestore emulator. Health endpoints can consume inference quota; a provider that ignores abort may keep consuming resources even after the caller has timed out. Manual pool may report degraded fallback for some unavailable selections; a Cloudflare-only choice is not substituted.
- **GitHub:** OAuth, status, repo list, text-file comparison, reviewed Agent push, a limited reviewed import of existing text files, reviewed same-repository PR creation, bounded read-only PR listing/inspection, and explicitly reviewed same-repository PR merge exist. No repository browser, full pull/sync/conflict UI, formal PR reviews, upstream grant revocation, complete audit trail or GitHub App. The comparison and atomic expected-HEAD mutation are mock-tested, not live verified; unsupported remote file modes and binary files fail closed. This is not a full synchronization workflow.
- **MCP/personal services:** No MCP SDK or connector framework; no Drive, Gmail, Photos or Meta integrations. Age/guardian consent, official scopes, permissions and app review need independent implementation and verification.
- **Data lifecycle:** No general retention engine, comprehensive database usage dashboard, billing estimates or verified backup. The maintenance worker only handles its documented bounded jobs.
- **Brand:** Public organization is OKGS, but legal/contact and certificate issuer references and legacy hosts/IDs are preserved pending confirmation and migration. `qorvyna.online` is the requested public website, not a verified live origin.
- **Security:** GitHub environment/private-key guards do not detect all secrets. External content remains untrusted; production needs defense-in-depth, monitoring, rate limiting and security review.

## MCP and dependency audit (latest local work)
The official SDK GitHub file reader is opt-in, read-only, approval-gated and mock-tested only; it is not a general MCP foundation and has not been tested with a real GitHub account or deployment. Other requested providers, server management and connector lifecycle are not implemented. See `MCP_ARCHITECTURE.md`.

A local `npm audit --omit=dev` after dependency refresh reported 8 affected packages: 6 high, 1 moderate, 1 low, including Zod 3, the Firebase client gRPC dependency and Next's bundled PostCSS. Re-run the audit against the deployment lockfile before release; these counts are not a release approval. Updating incompatible major versions or overriding transitive dependencies requires explicit compatibility/security review and complete regression testing. Reported advisories and actual exploitability depend on usage; do not treat absence of a critical finding as a clean audit.
