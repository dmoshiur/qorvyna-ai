# Final-round demo checklist

Before the demo, use a staging deployment with test Firebase users, a disposable GitHub repository and authorized provider credentials. Verify the actual origin, OAuth callback and Firebase domains; test provider models/limits, review GitHub push with a non-sensitive file, and ensure an independently verified backup exists. Do not present setup-dependent or unverified services as live.

Suggested sequence: (1) introduce QORVYNA AI by OKGS; (2) sign in as a test user; (3) show chat and model choice, explaining truthful fallbacks; (4) generate and validate a small project in Agent Studio; (5) connect a test GitHub account, review files and explicitly confirm a push; (6) show admin provider settings with masked keys; (7) explain the existing permission gateway and clearly state MCP and PR workflows are future work. Avoid showing credentials, personal data or private repositories. Have a local walkthrough ready if third-party services are unavailable.
